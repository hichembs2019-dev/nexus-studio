# nexus-studio

بوت Telegram يحوّل قصة أو سيناريو حقيقي إلى **فيلم** حقيقي: شخصيات/ممثلون
يتكلمون ويتحركون داخل مشاهد حقيقية (صوت حقيقي + مزامنة شفاه حقيقية)، **بدون
أي راوٍ** - لا شخصية باسم "راوي"، ولا سرد نصي فوق فيديو صامت. هذا هو المسار
الوحيد الموجود في هذا المستودع.

## كيف يعمل

المالك يعطي القصة (أو يبني سيناريو من فكرة قصيرة) ← **`DialogueWriterAgent`**
يستخرج طاقم الشخصيات الحقيقي (لا راوي، ممنوع في الكود نفسه - انظر تحت) ثم
الحوار المنطوق ← **المالك يقرأ ويوافق** (أو يعدّل/يحوّل أسطراً لنص على
الشاشة) ← عند الموافقة فقط، **`DialoguePipeline`** يصنع فعلياً: صوت حقيقي
(Azure TTS) لكل سطر منطوق، فيديو حقيقي بمزامنة شفاه حقيقية
(`fal-ai/wan/v2.2-14b/speech-to-video`) لكل سطر، صورة مرجعية حقيقية
فوتوغرافية لكل شخصية (`fal-ai/flux/dev`) مولّدة من وصفها في هذا السيناريو
بالذات - ثم دمج كل المقاطع في فيلم واحد.

**لا توجد أي صورة احتياطية/ثابتة بأي شكل** - لا لوحة من ست صور، ولا أي
صورة أخرى تُستعمل عند فشل التوليد الحقيقي. إن تعذّر توليد صورة حقيقية
لشخصية (لا وصف لها، أو لا `FAL_KEY`، أو فشل اتصال fal.ai فعلي)، أسطر هذه
الشخصية **تفشل وتُعرض باسمها وبالسبب الحقيقي** في رسالة البوت - لا تُنتَج
أبداً بصورة غير مولَّدة لهذه القصة بالذات (أمر المالك الصريح، 2026-10-21).

## لا راوي - بشكل مُلزم في الكود، لا طلب فقط

- `dialogue_writer.py`'s `_parse_cast` يرفض فوراً (`DialogueWriterError`) أي
  اسم شخصية يحتوي "راوي" أو "narrator" بأي صيغة، قبل بناء أي سيناريو -
  فحص حقيقي في الكود، لا تعليمة للموديل قد يتجاهلها.
- النماذج (`_CAST_SYSTEM_PROMPT`/`_LINES_SYSTEM_PROMPT`) تمنع أيضاً أي سطر
  يسرد أو يلخّص أحداثاً ماضية بصيغة راوٍ - كل سطر يجب أن يكون كلاماً مباشراً
  يقوله شخص لآخر داخل مشهد حقيقي.
- `/new` يرفض فوراً (قبل أي تكلفة) أي نص فيه اقتباسات حقيقية أكثر من عدد
  الأسطر التي سيبنيها، ويوجّه المالك إلى `/full` بدل أن يسمح للموديل
  باختيار/اختراع كلام - هذا بالذات ما تسبب سابقاً في فيديو خاطئ (امرأة تروي
  قصة) حقيقي التكلفة.
- **المسار القديم محذوف بالكامل من الكود**، لا موجود معطّلاً فقط: فيديو صامت
  (ComfyUI/Wan 2.2 T2V) + تعليق صوتي راوٍ فوقه (`WriterAgent`/`DirectorAgent`/
  `EpisodePipeline`/`ComfyUIClient`/`RemoteExecClient`/`wan_prompt_builder.py`
  وكل الأشكال/الثوابت التي استعملوها في `models.py`) - حُذفت كل هذه الملفات
  نهائياً في 2026-10-21 بأمر المالك الصريح والمتكرر. لا شيء من هذا موجود في
  هذا المستودع إلا بطلب مستقبلي صريح منه.

## البنية الحقيقية (بعد الحذف)

```
src/
  models.py                          # Character, DialogueLine, DialogueScreenplay,
                                      # ProducedDialogueClip, ProducedDialogueEpisode, PublishResult
  agents/
    dialogue_writer.py                # طاقم الشخصيات + الحوار (لا راوي، مفروض بالكود)
    publisher.py                      # الفيلم المُنتج -> رفع حقيقي للمنصات
  workflows/
    dialogue_pipeline.py              # ينتج كل سطر فعلياً (صوت+فيديو+صورة) ثم يدمج
  bot/
    conversation.py                   # منطق البوت الكامل (مُختبر 100%، بلا مكتبة Telegram)
    runner.py                         # الربط الفعلي مع Telegram
  integrations/
    fal_video_client.py               # fal-ai/wan/v2.2-14b/speech-to-video الحقيقي
    image_client.py                   # fal-ai/flux/dev الحقيقي (صور الشخصيات)
    tts_client.py                     # Azure Speech REST - صوت كل سطر منطوق
    reasoning_client.py               # Groq (أساسي) + Gemini (احتياطي)
    publishing_client.py              # YouTube حقيقي - منصات أخرى لم تُبنَ بعد
    telegram_client.py                # إرسال رسائل/فيديوهات Telegram
main.py                               # نقطة تشغيل البوت كخدمة دائمة (python -m src.main)
```

## التكلفة الحقيقية

- فيديو: `$0.10/ثانية` (480p)، `$0.15/ثانية` (580p)، `$0.20/ثانية` (720p) -
  `fal_video_client.py`'s `PRICE_PER_SECOND_USD` (أسعار fal.ai الموثّقة رسمياً).
  **لكن فاتورة حقيقية (2026-10-21) أثبتت أن fal.ai يحتسب كل طلب فعلياً
  بسعر 720p ($0.20/ثانية) رغم أن الكود يطلب دائماً 480p** - راجع
  `docs/SOURCES.md` ("fal.ai billed every real speech-to-video call at the
  720p rate..."). لذلك كل تتبّع مال حقيقي (التقدير قبل الموافقة وسقف
  `MAX_EPISODE_COST_USD`) يستعمل `REAL_BILLED_PRICE_PER_SECOND_USD`
  (= سعر 720p الموثّق) وليس سعر 480p، إلى أن يُحسم الخلاف مع fal.ai.
- صورة شخصية مرجعية: `$0.025/ميجابكسل` - `image_client.py`'s
  `PRICE_PER_MEGAPIXEL_USD`. مولّدة مرة واحدة لكل (سيناريو، شخصية) ومُخزَّنة -
  لا تُعاد عند إعادة محاولة نفس السيناريو.
- سطر بعلم `/caption` (نص على الشاشة بدل الكلام): **$0.00** حقيقياً - بدون
  TTS وبدون استدعاء fal.ai على الإطلاق.
- سقف صرف حقيقي صريح لكل محاولة إنتاج (`MAX_EPISODE_COST_USD`، افتراضياً
  `$10.0`) - يُفحص قبل كل سطر وكل صورة شخصية، فلا يمكن لسيناريو طويل أو
  خاطئ أن يتجاوز ما وافق عليه المالك في جلسة واحدة.

## استعمال البوت

بعد تعبئة `.env` (يحتاج `TELEGRAM_BOT_TOKEN` حقيقياً من [@BotFather](https://t.me/BotFather)،
و`FAL_KEY`/`AZURE_SPEECH_KEY`/`AZURE_SPEECH_REGION` حقيقية للإنتاج الفعلي):

```bash
docker compose up -d --build
```

ثم في محادثة البوت على Telegram:

| الأمر | الوظيفة |
| --- | --- |
| إرسال القصة كرسالة عادية (يمكن أن تكون طويلة، تنقسم لعدة رسائل) | تُجمَّع تلقائياً، حرفياً، بدون تلخيص |
| `/new [ثواني]` | يبني سيناريو حوار بعدد أسطر مقدَّر من المدة - يرفض إن كانت الاقتباسات الحقيقية أكثر من الأسطر الممكنة |
| `/full` | يستعمل **كل** اقتباس حقيقي في النص حرفياً، بدون اختيار ولا اختراع - للنص الذي كتبه المالك بنفسه |
| `/edit <رقم السطر> <نص جديد>` | يعدّل سطراً أو أكثر (سطر واحد لكل عدد جديد) |
| `/caption <أرقام الأسطر>` | يحوّل أسطراً محدَّدة من كلام منطوق إلى نص مكتوب على الشاشة - تكلفة $0 |
| زر **✅ موافقة** | يبدأ الإنتاج الحقيقي (دقائق، تكلفة حقيقية) |
| زر **📤 نشر على يوتيوب** | ينشر الفيلم الجاهز فعلياً على القناة المُعدَّة |
| `/cancel` أو زر **❌/🗑️** | يلغي المسودة الحالية |

كل منطق القرار (`src/bot/conversation.py`) مُختبر بالكامل بدون أي بوت حقيقي؛
الربط الفعلي مع Telegram (`src/bot/runner.py`) يحتاج بوتاً حقيقياً ليُختبر.

## الحالة

- ✅ طاقم شخصيات + حوار حقيقي (`DialogueWriterAgent`): مبني، مُختبر، ومُلزَم
  بعدم وجود راوٍ على مستوى الكود (ليس فقط تعليمة للموديل).
- ✅ إنتاج حقيقي (صوت + فيديو بمزامنة شفاه + صور شخصيات): مبني ومُختبر،
  مُثبَت حقيقياً (انظر `docs/SOURCES.md` لكل دليل حقيقي: زمن، تكلفة، ملفات
  فعلية).
- ✅ سقف صرف حقيقي، حماية من فقدان المقاطع المدفوعة عند فشل الدمج، إلغاء
  حقيقي للمهمات المتجاوَزة زمنياً على fal.ai.
- ✅ نص على الشاشة (`/caption`) بخط عربي حقيقي (RTL صحيح، مؤكَّد بمعاينة
  فعلية) بتكلفة $0.
- ✅ النشر (`PublishingAgent`) على **YouTube** حقيقياً، مُختبر على قناة
  حقيقية فعلياً (`docs/SOURCES.md` "Nexora channel setup").
- ⏳ TikTok/X/Instagram/Snapchat/Twitch/Kick: لا شيء مبني بعد.
- ✅ **المسار القديم (فيديو صامت + راوٍ) محذوف نهائياً من الكود** - 2026-10-21.
